# 🎡 돌려돌려 랜덤 돌림판 (Lucky Random Picker)

친구들과 식사비 부담, 설거지 당번, 커피 쏘기, 모임 역할 분담 등을 정할 때 공정하고 재미있게 사용할 수 있는 반응형 무작위 선정 웹 애플리케이션입니다.

![Preview](https://raw.githubusercontent.com/JINU08/dollimpan/main/preview.png)

## ✨ 주요 기능
- **간편한 참가자 등록**: 쉼표(`,`)나 줄바꿈으로 한 번에 여러 명의 이름을 복사/붙여넣기하여 등록 가능
- **캔버스 물리 룰렛**: 회전 속도가 서서히 감속하는 물리 엔진과 슬라이스 통과 시 바늘 튕김 틱(Tick) 사운드 적용
- **스피드 카드 롤링 모드**: 돌림판 외에 빠른 추첨을 위한 슬롯머신형 텍스트 롤러 지원
- **화려한 당첨 축하**: 당첨 시 화면 중앙에 눈에 띄는 당첨자 카드 및 은은한 축하 콘페티(Confetti) 연출
- **다시 뽑기 & 당첨자 제외 추첨**: 당첨된 인원을 자동으로 명단에서 제외하고 연속으로 다음 당번을 뽑을 수 있는 편의 기능
- **선정 기록 아코디언**: 과거 추첨 기록을 시간대별로 확인 및 관리 가능
- **감성적인 크림 베이지 디자인**: 눈이 편안한 아이보리 카드, 카라멜 브라운 버튼, 미니멀한 여백의 완성도 높은 반응형 UI (PC/모바일 지원)

## 🛠️ 기술 스택
- **HTML5** (Canvas 2D API)
- **CSS3** (반응형 플렉스/그리드, 모던 글래스모피즘 & 크림 베이지 테마)
- **Vanilla JavaScript** (ES6+, Web Audio API)
- **배포**: Vercel
